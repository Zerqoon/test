# Ikony Wymiaru ZERQONA v4

Wersja 4 nie korzysta z paczki „kryształowych” ikon. Ikony interfejsu są własnymi prostymi rysunkami wektorowymi tworzonymi w `src/graphics.js` przez Canvas (moneta, teczka, zegar, korona, torba, tarcza, puchar, bilet itd.).

Dzięki temu bot nie potrzebuje pobierać grafik podczas działania, styl jest spójny, a deployment nie zależy od zewnętrznego CDN.
