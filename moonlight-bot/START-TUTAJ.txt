START LOKALNY:

1. Zainstaluj Node.js 22.18 lub nowszy.
2. Skopiuj .env.example jako .env. Wpisz TOKEN, CLIENT_ID i GUILD_ID.
3. W Developer Portal włącz Server Members Intent i Message Content Intent.
4. Zaproś bota: bot + applications.commands. Uprawnienia są opisane w README.md.
5. Przenieś rolę bota nad nadawane role i moderowanych użytkowników.
6. W terminalu, w folderze projektu:

   npm ci
   npm run deploy
   npm start

7. Na Discordzie: /konfiguracja, /powitanie-test, /regulamin.
